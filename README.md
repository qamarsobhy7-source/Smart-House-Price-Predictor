# 🏠 Egypt Real Estate AI Predictor

AI-powered web application for predicting real estate prices in Egypt.

## 📊 Data

- **119,916** property listings
- **6** governorates: Cairo, Giza, Matrouh, Red Sea, Alexandria, Suez
- **19** property types
- **573** districts
- **881** compounds

## 🎯 Model

- **Algorithm**: CatBoost
- **R² Score**: 0.7061
- **MAPE**: 40.52%
- **Features**: 35

## ✨ Features

- 🎯 Price Prediction
- 📊 Market Analysis
- 🗺️ Interactive Map
- 🧮 Mortgage Calculator
- ⭐ Featured Properties
