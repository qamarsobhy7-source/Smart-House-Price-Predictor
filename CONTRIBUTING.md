# Contributing to SmartPrice

First off, thank you for considering contributing to SmartPrice! 🎉

## 🚀 Quick Start

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/Smart-House-Price-Predictor.git`
3. Create a branch: `git checkout -b feature/amazing-feature`
4. Install dependencies: `pip install -r requirements.txt`
5. Make your changes
6. Test locally: `streamlit run streamlit_app.py`
7. Commit: `git commit -m 'feat: add amazing feature'`
8. Push: `git push origin feature/amazing-feature`
9. Open a Pull Request

## 📋 Coding Standards

- **Python**: Follow PEP 8
- **Naming**: `snake_case` for variables, `PascalCase` for classes
- **Comments**: In English, concise
- **Docstrings**: For all public functions
- **Type hints**: Where possible

## 🎨 UI/UX Guidelines

- **Mobile-first**: Always test on mobile viewport
- **Bilingual**: All UI strings must support EN + AR
- **RTL Support**: Test Arabic layout
- **Dark Mode**: Test both light and dark themes
- **Accessibility**: Use semantic HTML, alt text for images

## 🧪 Testing

Before submitting a PR, ensure:
- [ ] `python -m py_compile <file.py>` succeeds
- [ ] App runs locally without errors
- [ ] Tested on mobile + desktop
- [ ] Tested in both English and Arabic
- [ ] No console errors

## 📝 Commit Convention

Follow [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` New feature
- `fix:` Bug fix
- `docs:` Documentation
- `style:` Formatting
- `refactor:` Code refactoring
- `perf:` Performance
- `test:` Tests
- `chore:` Maintenance

Examples:
- `feat: add mortgage calculator`
- `fix: correct Arabic RTL alignment`
- `docs: update installation instructions`
